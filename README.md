# LOLA ENGLAND

Premium women’s T-shirt storefront built with Next.js.

## Current build
- Responsive fashion storefront inspired by the original LOLA ENGLAND interface
- Women’s T-shirts only
- Product pricing and marketplace CTA structure
- Amazon / Flipkart fields ready for future seller links
- Owner-only admin area foundation
- Netlify configuration included

## Admin environment variables
Set these in Netlify before using the private dashboard:

- `ADMIN_PASSWORD`
- `ADMIN_SESSION_SECRET`

Do not commit real secrets to GitHub.
